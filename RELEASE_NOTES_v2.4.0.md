On top of [2.3.0](https://github.com/FromChaosComesClarity/EmuLatte/releases/tag/v2.3.0).

## The hero shows screenshots now

The wide panel at the top of the library used to draw only the scraped hero banners. It shows **screenshots** by default instead: a screenshot is what the game actually looks like, and a scraped library holds far more of them than it does wide banner art.

It is a setting, in the new Appearance section:

| Show | |
| --- | --- |
| **Screenshots** | In-game shots. The default. |
| **Hero art** | The wide scraped banners, as before. |
| **Box art** | The cover. Portrait art is shown whole, framed against a blurred copy of itself, rather than cropped into a letterbox slice. |
| **Whatever each game has** | Best available per game. The one to pick on a partly scraped library. |

Games without the chosen kind of image sit the round out, and if none of them have it the panel falls back to whatever they do have rather than going blank. The card says how much of your library each choice covers. A game with several screenshots gets a different one each time it comes round.

## Play and add to a playlist from the hero

The panel now carries **▶ PLAY** and **+ PLAYLIST**, acting on the game being shown at that moment. The release is named under the title too, when that title is shared with something else on the same system, so you can tell which of three *Action Fighters* you are about to launch.

**The cycle holds still while your pointer is over the panel.** Reaching for Play on something that changes every six seconds is how you launch the wrong game, so it stops changing as soon as you go near it.

## A home for the appearance settings

New **Appearance** section in Settings, between General and Library. What moved there:

- **Colour Theme** and **UI Scale**, out of General
- **Display Density**, **Gamepad Buttons** and **Sync Couch Mode colours with the desktop theme**, out of the Couch Mode card

Couch Mode keeps what it *does* in General: which screen it opens on, whether it starts there, whether it hides the cursor. There is a line in each card pointing at the other, so nothing became harder to find. The **Gallery hero** card above is new.

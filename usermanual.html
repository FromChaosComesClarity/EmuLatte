EMULATTE

“I use RetroArch BTW”
ROM library manager for the obsessively organized

1. What EmuLatte Is

EmuLatte is a ROM library manager. It keeps your emulation collection organised across every system you care about — importing ROMs, scraping art and metadata, tracking achievements, downloading trailers, and launching each game exactly the way you configured it.

It is not an emulator. It drives RetroArch (and any other emulator you point it at) and stays out of the way once a game is running.

It ships with 56 system presets, each carrying opinionated RetroArch core defaults so you are not starting from zero.

Two faces, one binary

The desktop face is the one you are looking at: detail-obsessed, built for a mouse and keyboard, where all the management happens. Couch Mode is a fullscreen, gamepad-first, play-only face for a TV or CRT. Same library, same database, no duplication. See section 19.

EmuLatte is part of the Cafe Neurotico ecosystem, and it is also a perfectly complete standalone app. Nothing here requires the rest of the suite.

2. Install & First Run

EmuLatte ships as a single AppImage. Make it executable and run it:

  • chmod +x EmuLatte.AppImage
  • ./EmuLatte.AppImage

Where you put the AppImage matters. EmuLatte stores its data in a GameManagerConfig/ folder next to the AppImage itself. Put it somewhere permanent — for example ~/Games/CNGM/ — before you start building a library. Moving the AppImage later means moving that folder with it.

If you already run Cafe Neurotico, drop EmuLatte alongside it so both share the same GameManagerConfig/ parent. That is what makes credential import (section 11) and export (section 21) work without any configuration.

On first launch the library is empty and no systems are defined. That is expected. The order of operations is: add a system (section 3), import ROMs into it (section 4), then scrape (sections 9–10).

3. Adding Systems

A system is a console or platform — SNES, PS1, Dreamcast. It owns a ROM folder, a default emulator core, and its own scraping and launch settings. Every game belongs to exactly one system.

Open Settings → Systems → Manage Systems. From there you can add a system from the bundled presets or define one by hand.

From a preset

The 56 presets cover the systems most people actually own ROMs for, and each arrives with a sensible default RetroArch core already chosen, plus the identifiers the scrapers need to search the right platform. Pick the system, point it at your ROM folder, and you are done.

By hand

If your platform is not in the list, create it manually. You will need to supply at least a name, a ROM folder and a launch method — either a RetroArch core or a custom command (section 14).

Per-system settings live here too. The system editor is also where you set a system's default core, its BIOS requirements, disc-reference repair, and RetroArch settings that should apply to every game on that platform.

4. Importing ROMs

Two ways in, both on the main toolbar:

  • Scan Folder — point EmuLatte at a directory and it sweeps it for ROMs matching the system's known extensions. This is how you import a collection.
  • Add ROM — add a single file by hand, for when a scan missed something or the file lives somewhere unusual.

Importing never moves, copies or renames your ROM files. EmuLatte records the path and leaves your collection exactly where it is. Removing a game from the library likewise deletes only the database row, never the file on disk.

Re-scanning later

Run the folder scan again after adding new ROMs. Games already in the library are skipped, so re-scanning is safe and is the normal way to pick up new arrivals. Couch Mode's Refresh does the same thing without leaving the sofa.

Multi-disc and archives

Multi-disc games are the usual sharp edge in any ROM collection. The system editor's disc-reference repair exists for exactly this: it fixes up .m3u and .cue files whose internal references point at paths that no longer exist, which is what normally breaks a disc-based game after you move or re-rip a collection.

Found duplicates? Settings → Data → Find Duplicate Games scans for repeated titles and lets you batch-remove the extras. It only ever removes library entries — your ROM files are never touched.

5. The Library & Gallery Views

The main window is your library. The left rail switches between views and opens Settings; the collapsible side panel filters by system and playlist.

The gallery is a cover wall. The list is denser and shows more metadata per row. Sort order is yours to choose and is remembered between sessions.

The search box filters by title as you type. It searches titles only — deliberately, so a search for "Mario" returns Mario games rather than every game whose description happens to mention him.

Favourites and Want to Play are two independent flags you can set from any game page. Both are filterable from the side panel, and both carry through to Couch Mode.

7. Editing Game Details

Scrapers are good, not infallible. The edit screen lets you correct anything by hand: title, description, developer, publisher, release date, genre, players, rating.

You can also replace any individual art asset — cover, hero, logo, screenshots — either by picking a different scraped candidate or by supplying your own local file. Hand-edited values are yours; a later scrape will not silently overwrite work you did deliberately.

8. Playlists

Playlists are named collections that cut across systems. A game can be in as many as you like, and adding it to one does not remove it from anywhere else.

Create them from the side panel, add games from any game page, and filter the library by playlist from the sidebar. They carry through to Couch Mode, which is the real point — "Saturday Night Co-op" is a much better way to browse from a sofa than "Sega Genesis".

9. Art Scraping

EmuLatte pulls art from five sources, and they are genuinely good at different things. The scraper picker on the game page lets you choose per game, so you can take metadata from one and art from another.

SteamGridDBArtwork only — covers, heroes and logos. The best-looking modern art, and the place to go when you want a specific style.Free API key
TheGamesDBRetro-focused metadata and boxart. Strong on older consoles.Free API key
IGDBMetadata and artwork via the Twitch API. Excellent, well-curated descriptions.Client ID + Secret

Credentials for all of them live in Settings → Scrapers, and each has a Test button so you find out immediately whether a key works rather than halfway through a scrape.

A practical combination: ScreenScraper for metadata and the bulk of your art, then SteamGridDB to replace the covers and heroes on the handful of games you care most about looking right.

Art types

  • Cover — the boxart shown in the gallery wall
  • Hero — the wide background image on the game page and in Couch Mode
  • Logo — the transparent title treatment laid over the hero
  • Screenshots — the in-game shots, also used by the Couch Mode screensaver

10. Metadata Scraping

Metadata is everything that is not art: description, developer, publisher, release date, genre, player count, rating. It comes from the same picker and the same five sources.

If a scrape matches the wrong game — common with regional variants, revisions and anything called "Adventure" — use refine to search manually and pick the correct result. The system's platform identifier is passed to the scrapers, so results are already filtered to the right console before you even look.

ScreenScraper enforces per-account rate limits. Scraping a very large collection in one sitting may pause partway through. This is the service protecting itself, not a fault in EmuLatte — wait, then continue.

11. CNGM Credential Import

If Cafe Neurotico is installed alongside EmuLatte, Settings → Scrapers → Import from CNGM copies your existing IGDB and SteamGridDB credentials across so you do not have to register twice or paste keys by hand.

This reads CN's settings out of the shared GameManagerConfig/ folder. If the button reports nothing found, the two apps are not sharing a parent folder — see section 2.

12. The Emulator Scanner

Settings → Systems → Add Emulators scans your machine for installed emulators and offers to assign them to existing systems or create new systems around them.

It is the fastest way to get a working setup on a machine that already has emulators installed, and it saves typing launch commands by hand for anything it recognises.

13. RetroArch & Cores

EmuLatte runs RetroArch on its own config

Your host retroarch.cfg is never read and never written. EmuLatte seeds a clean config of its own (importing only folder paths) and drives RetroArch with it. Nothing you do here can disturb a RetroArch setup you already rely on.

RetroArch is auto-detected in both native and Flatpak installs. The Settings → RetroArch pane is where you manage all of it:

  • Edit RetroArch Settings — the full settings tree (video, audio, input, latency, shaders, achievements and the rest) edited from inside EmuLatte.
  • Configure in RetroArch — opens RetroArch's own menu running on EmuLatte's config. Changes you make there save back here.
  • Re-import Paths — re-points cores, BIOS and saves at the current machine. Use this after restoring a backup on a different computer.
  • Scan Cores / Download Cores — finds installed cores, or fetches ones you do not have yet.
  • Back Up / Restore Settings — zips your RetroArch overrides plus a copy of retroarch.cfg to carry to another machine.

Express RetroArch

Settings → Express is the same machinery in plain language: the settings that actually matter, described in words rather than RetroArch's own vocabulary, applied instantly. A ★ marks the recommended pick. Shaders included. Start here; drop into the full settings tree only when Express does not cover what you want.

Core overrides

Cores are chosen in three layers, most specific winning:

  1. The system default, from the preset or your own choice
  2. A per-system RetroArch setting, in the system editor
  3. A per-game override, from the game page's RetroArch button

Per-game overrides are how you handle the one game on a platform that needs a different core or different settings, without disturbing the other four hundred.

Save states

The Save State Manager (Settings → RetroArch, or the game page) browses save states across your whole library. You can label them, launch straight into one, delete them, and back them up. Labels are yours — "before the boss" beats "slot 3".

14. Custom Emulator Commands

RetroArch is the default, not a requirement. Any system or individual game can instead use a fully custom command — standalone emulators, wrapper scripts, anything you can run from a shell.

Set it on the system to apply to everything on that platform, or on a single game to override just that one. This is how you handle the platforms RetroArch does not serve well, and it is why the tagline is a joke rather than a limitation.

15. BIOS Files

Some systems will not run without their BIOS. EmuLatte ships a database of what each platform requires and checks whether you have it.

The system editor shows BIOS status for that platform: which files are needed, and which are present. You can add a file you already own individually, or point EmuLatte at a folder and let it pick out the ones it recognises. Files are copied into RetroArch's system/ folder where the cores expect to find them.

EmuLatte does not supply BIOS files and will not download them. It only tells you what is missing and files what you already own into the right place.

16. RetroAchievements

Put your retroachievements.org username and API key into Settings → Scrapers (the API key is in your profile settings on the site) and press Test Credentials.

EmuLatte then shows achievement sets and your progress on supported games. The achievement filter on the game page separates earned from unearned.

Achievements have to be switched on inside RetroArch as well — the Achievements section of the RetroArch settings tree, or via Express. EmuLatte drives its own config, so enabling it here does not touch any other RetroArch install you have.

17. Trailers

EmuLatte downloads trailers with a bundled yt-dlp and ffmpeg — both ship inside the AppImage, so there is nothing to install.

From a game page, search for a trailer, pick the right result, and download it. Downloaded trailers are stored locally and play in an embedded player. There is no streaming and no account.

Closing the player stops the video. Both the ✕ button and Esc stop playback and release the file.

18. Game Manual PDFs

This is the manual for EmuLatte. The Manual button on a game page is a different thing entirely: it fetches the scanned manual for that game — the actual printed booklet that came in the box — from ScreenScraper, and opens it in its own window with Chromium's PDF viewer.

It needs ScreenScraper credentials (section 9), and coverage depends on what ScreenScraper has for that title. Fetched manuals are cached locally, so a manual you keep opens instantly next time.

19. Couch Mode

Couch Mode is EmuLatte's fullscreen, gamepad-first, play-only face — built for a TV, a projector or a genuine CRT. It reads the same library. It deliberately cannot edit anything: it is for playing games, not managing them.

Enter it with ▶ GO FULLSCREEN in the top bar, from Settings → General, or set Start in Couch Mode on launch to boot straight into it.

Display types

Three separate layouts, each with its own tuning — switch in Settings → Display Type inside Couch Mode:

  • Horizontal — the standard widescreen layout
  • Vertical — for a rotated or portrait display
  • CRT Mode (640×480) — a genuinely low-resolution layout with a three-column game page, built to be readable on a real CRT rather than merely shrunk down

Returning from a game

The Return Combo is a button combination you hold while a game is running to come back to Couch Mode. Six combinations are available, including hold-for-two-seconds variants that are much harder to trigger by accident.

Match it to RetroArch's own Close combo and a single press both closes the game and returns you to Couch Mode.

Save states, screensaver and sound

  • Manage Save States — the save-state manager, usable from the sofa
  • Screensaver — a screenshot slideshow after 1, 3, 5 or 10 minutes idle, or off
  • Sound — ambient background music and interface sound effects, with volume
  • Now playing — shows what launched, and what you are returning from

RetroArch Simple Setup

The Express settings from the desktop face, rebuilt for a gamepad, including the shader submenu. The two stay in sync — it is the same configuration, not a second copy.

Other Couch settings

  • Refresh — rescans your ROM folders for new games without going back to the desktop
  • Navigation Mode — cover wall or list-with-details
  • Carousel Label — logo, name, or both on the start carousel
  • Display Density — scales the whole interface for low-resolution screens
  • Sync Desktop Colors — mirror the desktop face's theme instead of Couch's own

On Wayland, applications cannot choose which display they open on. Leave Target Screen on Current screen, drag the EmuLatte window onto your TV first, then Go Fullscreen. The Target Screen setting works on X11, Windows and macOS.

20. Themes & Fonts

EmuLatte ships 92 themes in 10 categories, and both faces carry all of them. Pick one from Settings → General → Choose Theme, or from Color Theme inside Couch Mode.

The categories run from Originals & System and BrewBalance through Gaming Legends, Linux Ricing, Sci-Fi Universes and Horror Realm, to Systems — twenty retro-OS palettes reproducing MS-DOS, Windows 3.1, Windows 95, Windows XP, Classic MacOS, Amiga Workbench, NeXTSTEP, BeOS, OS/2 Warp, RISC OS, Solaris CDE, ZX Spectrum, Commodore 64, GEOS, Atari ST, IBM 3270, Teletext, and amber and green CRT phosphor.

Each Systems theme carries its own era typeface — the interface actually changes font to match the operating system it is imitating. All fonts are bundled in the AppImage; nothing is fetched from the network.

Couch Mode additionally offers a Press Start 2P interface font under Fonts, with long-form text kept in the readable face regardless.

UI Scale (50%–150%) is separate, under Settings → General.

21. Exporting Games to Cafe Neurotico

How games actually get to Cafe Neurotico

By exporting them from inside EmuLatte — nothing else. Cafe Neurotico does not read EmuLatte's database and has no "show emulation" toggle.

Press ADD TO CAFENEUROTICO on a game page. EmuLatte copies that game's art across and writes an ordinary row into CN's games.db with its Store set to Emulation, carrying EmuLatte's own launch command. From then on it launches from Cafe Neurotico or CREMA exactly as it does here.

Export is one-directional and per-game. Re-exporting a game you already exported updates it in place rather than creating a duplicate. Management of the ROM collection always stays in EmuLatte — CN sees a game, not your library.

This requires both apps to share a GameManagerConfig/ parent folder (section 2).

22. Your Data & Backups

Everything EmuLatte owns lives in one folder, next to the AppImage:

Your ROM files are not in here and are never copied into it. EmuLatte stores paths and leaves your collection where you put it.

Backups

From Settings → Data:

  • Back Up EmuLatte — the library, art, trailers, credentials and RetroArch config, plus your RetroArch save states
  • Back Up Cafe Neurotico Suite — everything in GameManagerConfig (EmuLatte, Cafe Neurotico, CREMA and the Clock) plus save states, as a full 1:1 copy
  • Restore from Backup — overwrites current data and restarts EmuLatte

Restoring on a different computer: ROM paths and RetroArch folders are machine-specific. After a restore on a new machine, run Settings → RetroArch → Re-import Paths to re-point cores, BIOS and saves at that machine. Your ROM folders may also need re-pointing if the collection lives somewhere else on the new machine.

Artwork looks after itself. Art paths are stored absolutely, so moving the AppImage or restoring into a different folder would otherwise leave every cover pointing at the old location. EmuLatte re-points them to the current folder on startup. Images you supplied yourself from outside the data folder are left exactly where they are.

Reclaiming space

Clean Unused Images & Videos deletes downloaded art and trailers that are no longer linked to any game. It reports what it found before removing anything.
